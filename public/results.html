About these results

This is not a certification. Each entry shows what one tester saw with one wallet build on one date, and anyone can repeat it on their own device with the same wallet build and test.

  • Recorded by the instance: published from the run records of the Wallet QA instance named in the entry.
  • Self-reported: a report uploaded from another Wallet QA instance; this instance did not see the runs.
  • Tester-attested: the pass rests on the tester's checklist answers, not on EUDIPLO protocol evidence.

Entries contain the wallet, build, platform, device, versions and verdicts only. To have an entry removed, open an issue in EUDIPLO/wallet-qa.
